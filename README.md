# Cache Simulator

一个用 C 语言实现的缓存模拟器，用于学习和演示缓存的工作原理。

## 功能特点

- 模拟组相联缓存（A 和 B 合并版）
- 使用 LRU（最近最少使用）替换策略
- 交互式菜单，无需记忆命令行参数
- 显示命中率等统计信息
- 支持自定义格式的 trace 文件，方便手动编写测试用例

## 编译与运行

```bash
# 编译
make

# 运行
./cache_sim

# 清理编译产物
make clean
```

## 使用说明

### 1. 运行程序

```bash
./cache_sim
```

### 2. 输入缓存参数

程序会提示你输入三个参数：

 s  组索引位数，组数 = 2^s  
 E  每组合路数  2 → 2路组相联 
 b  块偏移位数，块大小 = 2^b 字节 

### 3. 输入 trace 文件路径

输入你准备好的 trace 文件路径，例如：

```
examples/simple.trace
```

程序会自动读取并模拟缓存访问，最后输出统计结果。

## Trace 文件格式

程序使用自定义的 trace 格式，每行格式为：`操作 地址,大小`

 L  读数据 
 S  写数据 
 M  修改数据（先读后写，算2次访问） 
 I  指令（忽略） 

示例文件 `examples/simple.trace`：

```
L 0x1000,1
L 0x1004,1
L 0x1008,1
S 0x1000,1
M 0x1004,1
L 0x2000,1
L 0x2004,1
L 0x3000,1
S 0x3004,1
M 0x3008,1
```

此格式受 valgrind trace 启发，但简化了格式，方便手写测试。
